# 在线调试

本页介绍文档页面 `/csap-api.html` 里的接口调试功能：环境切换、全局请求头、鉴权方案、发送请求、请求历史与重放、命名快照，以及这些数据保存在哪里。

:::tip 版本说明
本页的环境切换、全局请求头、鉴权、请求历史与重放、命名快照和中英文切换从 1.1.1 起可用。1.1.0 的 jar 里打包的是旧版文档页面，没有这些功能，请升级到 1.1.1。
:::

## 两个调试入口

在左侧选中一个接口后，右侧顶部有三个标签：

| 标签 | 作用 |
| --- | --- |
| 参数文档 | 只展示请求头、请求参数、返回参数 |
| 在线测试 | 早期的简易调试：按文档参数生成一个 JSON 模板，填好后点「发送」 |
| 试运行 v2 | 完整的调试面板，本页后面讲的环境、全局请求头、鉴权、历史、快照都只作用于它 |

「在线测试」的行为比较固定：

- GET / DELETE 只把 `QUERY` 和未声明类型的参数放进模板，POST / PUT / PATCH 只放 `BODY` 参数。`PATH`、`HEADER` 类型的参数不在模板里，手动在 JSON 里加上同名字段后，会分别替换到路径的 `{name}` 上、作为请求头发送。
- **不会**套用环境、全局请求头和鉴权方案。
- 超时固定 10 秒，只支持 GET / POST / PUT / DELETE / PATCH。

需要带 Token、切环境或者反复调试时，请用「试运行 v2」。

## 试运行 v2

面板由一个地址栏和请求编辑区组成：

- **方法**：GET、POST、PUT、DELETE、PATCH、HEAD、OPTIONS。
- **URL**：打开面板时自动填成「当前服务地址 + 接口路径」。路径里的 `{id}` 这类占位符不会自动替换，需要手动改成实际值。
- **Headers / Query**：键值表，每行可以单独启用或停用。打开面板时为空，不会从文档自动带入参数。
- **Body**：「无 Body」「JSON」「Plain Text」三种。选 JSON 时发送前会先校验格式；GET 和 HEAD 不发送 Body。
- 地址栏右侧有「发送」「中止」，以及打开「请求历史」「请求快照」的两个图标按钮。

地址栏上方的标签会显示这次发送会用到的环境、生效的全局请求头条数和鉴权方案名称。

发送后，响应区显示状态码、耗时、大小，并分 Body / Headers / Raw 三个标签展示。JSON 会格式化显示；图片类型的响应会用同一个 URL 再加载一次显示出来；其他二进制内容（PDF、压缩包、音视频等）不在页面里展示。请求没有拿到 HTTP 响应时会显示失败原因，分为网络错误（多数是跨域）、超时、已取消、配置错误（例如 URL 既不是 `http(s)://` 开头也不是 `/` 开头）。

### 发送前的合成顺序

点击「发送」后，面板按下面的顺序拼出最终请求：

1. 用当前环境的变量展开 URL 里的 `{{变量}}`；如果 URL 是以 `/` 开头的相对路径，再在前面拼上环境的 Base URL。
2. 合并请求头，后面的覆盖前面的（请求头名不区分大小写）：全局请求头（全局 → 服务 → 环境作用域） → 面板里填写的 Headers → 鉴权方案生成的请求头。
3. 合并 Query：面板里的 Query，再加上鉴权方案生成的 Query 参数（同名时鉴权方案优先）。
4. 请求头和 Query 的值里的 `{{变量}}` 也会展开。**Body 不做变量展开。**

## 环境

页面顶部的「环境」下拉框用来切换当前环境，「管理环境...」打开环境管理抽屉。每个环境有：

| 字段 | 说明 |
| --- | --- |
| 名称 | 最多 32 个字符 |
| Base URL | 只拼接到以 `/` 开头的相对 URL 前面；`http(s)://` 开头的 URL 原样发送。留空表示使用页面所在的源 |
| 颜色标记 | 在下拉框和面板标签上显示 |
| 变量 | 名称 / 值对，在 URL、请求头、Query 和鉴权配置里用 `{{名称}}` 引用 |

`{{baseUrl}}` 是保留变量，始终解析为当前环境的 Base URL，不能在变量表里覆盖。引用了不存在的变量时，`{{xxx}}` 会原样保留在请求里，方便发现拼写错误。

没有选择环境时，请求按面板里的 URL 原样发送。

## 全局请求头

顶部的「请求头」按钮打开全局请求头抽屉。每条规则属于下面三种作用域之一：

| 作用域 | 生效条件 |
| --- | --- |
| 全局 | 所有请求 |
| 服务 | 当前在「切换服务」里选中的服务与规则里填写的服务地址一致 |
| 环境 | 当前环境就是规则所属的环境 |

同名请求头按 全局 → 服务 → 环境 的顺序覆盖，再被面板里手填的请求头覆盖。值支持 `{{变量}}`。

比较服务地址时会先做规范化：协议和主机名转小写，去掉查询串和 `#` 片段，去掉末尾的 `/csap/apidoc/parent` 和 `/`。所以 `https://x.com/csap/apidoc/parent` 和 `https://x.com` 视为同一个服务。

:::tip 单服务部署
没有配置[网关聚合](/guide/gateway-aggregation)时，「切换服务」下拉框是空的，「服务」作用域的规则永远不会命中。单服务场景请用「全局」或「环境」作用域。
:::

## 鉴权方案

顶部的「认证」按钮打开认证方案抽屉。一个方案就是一套可复用的凭证，支持四种类型：

| 类型 | 生成的内容 |
| --- | --- |
| Bearer Token | 请求头 `Authorization: Bearer <token>` |
| Basic Auth | 请求头 `Authorization: Basic <base64(用户名:密码)>` |
| API Key | 位置可选 Header（请求头）、Query（查询参数）或 Cookie，参数名默认 `X-API-Key` |
| OAuth2 (Client Credentials) | 先换取 access token，再按 Bearer 方式附加 |

字段值里可以写 `{{变量}}`，发送时按当前环境展开，方便不同环境用不同凭证。

**OAuth2 Client Credentials**：第一次发送时，浏览器向 Token URL 发一个 `application/x-www-form-urlencoded` 的 POST，参数为 `grant_type=client_credentials`、`client_id`、`client_secret`，填写了 Scope 时再加 `scope`。返回的 `access_token` 会被缓存，到期前 30 秒内视为过期并重新获取；响应里没有 `expires_in` 时按 1 小时计算。抽屉里可以看到缓存状态，也可以手动清空缓存。Token URL 同样由浏览器直接请求，需要对方允许跨域。

**服务绑定**：方案要绑定到服务后才会在发送时自动生效。配置了网关聚合时，从服务列表里选择；没有配置时是一个输入框，可以输入服务地址或标识。绑定标识填 `*` 表示默认方案：当前服务没有单独绑定、或者没有选择服务时使用它。单服务部署一般就绑定 `*`。

:::warning Cookie 不会被发送
API Key 选择 Cookie 位置时，浏览器不允许 JavaScript 为跨域请求设置 `Cookie` 请求头，这部分会被丢弃，响应区上方会出现提示。需要靠 Cookie 鉴权时，先在浏览器里登录目标站点，再在「设置」里打开「跨域请求附带 Cookie (withCredentials)」，并让目标服务返回 `Access-Control-Allow-Credentials: true` 和具体的 Origin。
:::

:::tip 后端的 @DocAuth / @DocGlobalHeader
在 Controller、方法或包上标注 `@DocAuth`、`@DocGlobalHeader` 后，文档数据里每个方法会带上 `authHint` 和 `globalHeaderHints` 字段（见 [REST 接口](/api/rest)）。1.1.1 起，打开试运行面板时会按这两个字段预填：`@DocGlobalHeader` 预填请求头（「全局请求头」里已有的不预填）；`@DocAuth` 为 bearer / basic 时预填 `Authorization` 前缀，为 API Key 时按位置预填 header 或 query，为 OAuth2 Client Credentials 时只显示“建议认证”标签；当前服务已绑定鉴权方案时不预填。没有值的预填行默认不启用，预填内容不会写入设置。1.1.0 的页面不读取这两个字段。
:::

## 跨域与设置

试运行 v2 由浏览器直接把请求发给目标服务，不经过 CSAP Apidoc 的后端。文档页面和目标服务不同源时，目标服务必须返回正确的 CORS 响应头，否则只能看到「网络错误」。

顶部「设置」抽屉的「试运行」一栏有三项：

| 设置 | 说明 |
| --- | --- |
| CORS 代理 URL | 保存一个代理地址，设计上会把目标地址 URL 编码后拼在它后面 |
| 请求超时（毫秒） | 1000 到 300000 |
| 跨域请求附带 Cookie (withCredentials) | 打开后跨域请求携带浏览器 Cookie，默认关闭 |

:::tip 版本说明
1.1.1 起三项设置都生效。1.1.0 中「CORS 代理 URL」和「请求超时」只会被保存，发送时没有读取：请求不经代理，超时固定为 30 秒。
:::

DevTools 模块另外提供了一个服务端转发接口 `POST /csap/apidoc/devtools/proxy`，默认关闭，开启方式和安全注意事项见 [DevTools](/guide/devtools)。它的请求格式是 JSON（`method`、`url`、`headers`、`body`）。1.1.1 起，「CORS 代理 URL」填以 `/csap/apidoc/devtools/proxy` 结尾的地址时，试运行会按这个格式把请求交给它转发；填其他地址时，按“代理地址 + URL 编码后的目标地址”拼接。

## 请求历史与重放

试运行 v2 每发送一次（无论成功失败）都会自动记一条历史，最多保留最近 50 条，新的在前。点击地址栏旁的历史图标打开「请求历史」：

- 每条记录保存方法、URL、Headers、Query、Body，以及响应摘要：状态码、耗时、大小，失败时记录失败原因。**响应 Body 不保存。**
- 保存的是你在面板里填写的内容，不是合成后的最终请求，所以全局请求头和鉴权凭证不会进入历史。
- 「重放」把这条记录回填到面板，不会立即发送；再点「发送」时会按当前的环境、全局请求头和鉴权方案重新合成。
- 可以删除单条记录，或「清空」全部。

## 命名快照

快照是手动保存、不会被自动淘汰的请求模板，适合保存常用的调试请求并分享给同事。点击地址栏旁的快照图标打开「请求快照」：

- **保存当前请求**：名称必填，说明可选。保存的内容和历史一样只有请求部分（方法、URL、Headers、Query、Body 及 Body 类型），不含响应。URL 为空时不能保存。
- **加载**：回填到面板，和重放一样在发送时重新合成环境、请求头和鉴权。
- **重命名 / 修改说明**、删除单条、清空全部。
- 最多 500 条。

**导出**会下载 `csap-apidoc-snapshots-YYYY-MM-DD.json`，内容就是本地存储的原样数据：

```json
{
  "version": 1,
  "snapshots": [
    {
      "id": "…",
      "name": "查询订单",
      "description": "测试环境常用",
      "createdAt": 1763337600000,
      "updatedAt": 1763337600000,
      "method": "GET",
      "url": "/orders/{{orderId}}",
      "headers": {},
      "query": { "expand": "items" },
      "body": null,
      "bodyKind": "none"
    }
  ]
}
```

**导入**时先选择模式：

- **合并**：把文件里的快照加到现有列表前面；`id` 与已有快照重复时，会给导入的那条换一个新 `id`，两条都保留。
- **覆盖**：先清空现有快照再导入。

文件不是合法 JSON 或缺少 `version` / `snapshots` 时整体导入失败，现有数据不变；个别格式不对的条目会被跳过，完成提示里会显示新增和跳过的条数。

:::tip
快照里如果直接写了 Token，导出文件里也会带着它。分享前建议把凭证改成 `{{变量}}` 引用，或者交给鉴权方案处理。
:::

## 数据保存在哪里

以上所有配置和记录都只保存在**当前浏览器的 localStorage** 里，没有任何服务端存储，也不会上传。换浏览器、换电脑或清除站点数据后需要重新配置。localStorage 按源（协议 + 域名 + 端口）隔离，同一个浏览器访问不同地址的文档页面，数据也互不相通。

| localStorage 键 | 内容 |
| --- | --- |
| `csap-apidoc:environments` | 环境列表和当前环境 |
| `csap-apidoc:headers` | 全局请求头规则 |
| `csap-apidoc:auth-schemes` | 鉴权方案和服务绑定，敏感字段只存保险库引用 |
| `csap-apidoc:vault` | 保险库（明文模式），保存 Token、密码、API Key、Client Secret 和 OAuth2 缓存的 access token |
| `csap-apidoc:vault.encrypted` | 保险库（加密模式） |
| `csap-apidoc:settings` | 设置 |
| `csap-apidoc:tryItOutHistory` | 请求历史 |
| `csap-apidoc:tryItOutSnapshots` | 命名快照 |
| `csap-apidoc:locale` | 界面语言 |
| `csap-apidoc:theme` | 界面主题（1.2.0 起） |

全局请求头的值和环境变量不进保险库，始终以明文保存。

### 保险库加密

默认情况下凭证以明文保存在 localStorage。在「设置 → Vault 加密」里可以打开加密并设置主密码：

- 用 PBKDF2-SHA256（200,000 次迭代、16 字节随机盐）从主密码派生密钥，每条凭证用 AES-GCM 256 和独立的 12 字节随机 IV 加密。
- 加密后，刷新页面需要先输入主密码解锁；锁定期间读不到凭证，发送请求时不会附带鉴权信息。
- 「空闲自动锁定」默认 30 分钟，设为 0 表示不自动锁定；也可以「立即锁定」。
- 可以修改主密码，或输入当前主密码关闭加密（凭证转回明文）。
- **主密码无法找回。** 忘记后只能「重置全部」。

### 导出、导入与重置

「设置 → 数据」一栏：

- **导出 JSON**：下载 `csap-apidoc-config-YYYY-MM-DD.json`，包含环境、全局请求头、鉴权方案、设置，以及保险库内容。保险库处于明文模式或已解锁时，凭证会**以明文**写进这个文件；已锁定时不包含凭证。请求历史和快照不在其中，快照请用快照抽屉单独导出。
- **导入 JSON**：用文件内容覆盖当前的环境、全局请求头、鉴权方案和设置，保险库切回明文模式（需要的话重新开启加密），然后刷新页面。
- **重置全部**：删除所有以 `csap-apidoc:` 开头的 localStorage 键，包括历史、快照、语言和主题设置，然后刷新页面。

## 界面语言

页面右上角可以在简体中文和 English 之间切换，默认简体中文，选择保存在 `csap-apidoc:locale`。

## 亮色 / 暗色主题

1.2.0 起，页面右上角的主题按钮可以选择「亮色」「暗色」或「跟随系统」，默认跟随系统：操作系统切换深浅色时页面会立即跟着变。选择保存在 `csap-apidoc:theme`（值为 `light`、`dark` 或 `system`），浏览器禁用 localStorage 时仍可切换，只是刷新后回到跟随系统。

暗色主题覆盖文档页面本身、Ant Design 组件和代码编辑器（请求 / 返回示例、在线测试的响应体），导出的文件内容不受主题影响。
