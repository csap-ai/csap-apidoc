# 版本对比与破坏性变更检测（1.4.0 计划）

:::warning 1.4.0 计划，用法待定
这个功能**计划随 1.4.0（2026-12-22）发布，当前已发布的版本（Java 1.3.0、Go v0.1.1）没有**。本页先说明目的和适用场景，配置、用法和示例等设计约定审定后补充。
:::

## 它解决什么问题

接口改动后，调用方是否会被破坏（删字段、改类型、必填变化等）往往到联调甚至上线后才发现。这个功能比较两个版本的文档，列出差异并识别破坏性变更，可以放进 CI 里，在合并前拦截。Go 侧计划提供命令行工具 `csap-apidoc-diff`。

## 适用场景

- 在 CI 中比较当前分支与主干的文档，发现破坏性变更时让流水线失败；
- 发布前生成"这次改了什么"的差异清单；
- 多服务场景下提前通知调用方（团队版在此基础上做跨服务汇总）。
