## 它解决什么问题

接口的请求和返回结构已经在文档里，但其他工具（校验库、代码生成器、网关、测试框架）更习惯用 JSON Schema。这个功能把文档里的结构导出成 JSON Schema，也能从已有的 JSON Schema 导入结构，避免两边各维护一份。

## 适用场景

- 用已有的 JSON Schema 工具校验接口的请求或返回；
- 把文档结构交给代码生成器或网关使用；
- 把已有的 Schema 导入作为字段的起点。
