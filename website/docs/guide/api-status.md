## 它解决什么问题

接口有"开发中、完成、过时"的状态（`ApiStatus`），但目前只是一个字段，没有在文档和 AI 调用里体现，也没有管理入口。这个功能让状态在文档页和 MCP 里可见：开发中的接口不会被当成稳定接口使用，过时的接口有明确提示。状态枚举见 [注解参考](/api/annotations#apistatus)。

## 适用场景

- 新接口开发期间对外标记"开发中"，避免调用方过早依赖；
- 接口准备下线时标记"过时"，提醒调用方迁移；
- 让 AI 通过 [MCP](/guide/mcp) 调用时能区分哪些接口可用。
